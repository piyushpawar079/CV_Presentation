# Virtual Presentation App

A hands-free presentation control system that allows users to navigate slides and draw annotations using intuitive hand gestures through computer vision technology.

## 🎯 Overview

Virtual Presentation App is an innovative presentation tool that transforms how users interact with their slideshow presentations. Instead of using traditional presentation remotes or keyboard shortcuts, presenters can use natural hand movements to control slides and add real-time annotations to their presentations.

## ✨ Features

### 📊 Slide Navigation
- **Forward Navigation**: Show pinky finger to move slides forward
- **Backward Navigation**: Show thumb to move slides backward
- **Gesture Recognition**: Accurate finger detection for reliable slide control
- **Smooth Transitions**: Seamless slide progression with gesture commands

### ✏️ Drawing Annotations
- **Index Finger Drawing**: Use index finger to draw directly on presentation slides
- **Real-time Annotations**: Live drawing overlay on current slide content
- **Visual Feedback**: Instant visualization of drawing strokes on slides
- **Interactive Presentation**: Engage audience with dynamic content highlighting

### 🔄 Drawing Management
- **Undo Function**: Specific gesture to undo recent drawing actions
- **Clean Interface**: Remove unwanted annotations with simple hand movements
- **Drawing Control**: Precise annotation management during presentations
- **Gesture-Based Editing**: Intuitive hand gestures for drawing modifications

### 🎯 Presentation Control
- **Hands-Free Operation**: Complete presentation control without physical devices
- **Remote Presentation**: Control slides from anywhere within camera range
- **Professional Flow**: Maintain natural presentation rhythm with gesture controls
- **Multi-Modal Interaction**: Combine slide navigation with real-time annotations

## 🛠️ Technology Stack

- **Computer Vision**: Hand detection and finger gesture recognition
- **Presentation Integration**: Direct slide control and annotation overlay
- **Real-time Processing**: Low-latency gesture-to-action conversion for smooth presentation flow
